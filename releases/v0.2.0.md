# Vantyr v0.2.0

This release brings device-owned feature permissions, exclusive remote control,
mobile interaction improvements, and a more useful Recall and fleet dashboard.

## Upgrade notes

- Optional agent modules start disabled until authorized in the device's Settings
  → Security panel or with `--module-permission MODULE on`. Enable the modules
  you need on each device after upgrading. The server can stop modules; it cannot
  grant them through the module protocol.
- Clipboard transfer requires the device's `clipboard` permission and an active
  exclusive control session. Transfers are explicit, text only, and limited to
  64 KiB of UTF-8 text. There is no automatic clipboard synchronization.
- Standard local approval uses the agent's operating-system identity. Authorized
  remote shells, scripts, file access, or input can affect local permission
  storage or settings. This mode does not provide protected physical consent.
- Back up the PostgreSQL database and recording storage before upgrading. The
  server applies embedded database migrations on startup; restoration of a
  production backup has not been verified by this release's automated tests.

## Changes

- Explicit clipboard transfer in both directions, with browser permission errors
  and manual text fallback.
- Direct touch and trackpad control, drag and scroll actions, software keyboard
  composition, local zoom/pan, and fullscreen fallback for mobile browsers.
- Exclusive control leases, held-input cleanup, and input coordinates bound to
  the displayed capture and physical monitor geometry.
- Reliable device removal, stable sorting, replacement enrollment, favorites,
  saved fleet views, and bounded fleet telemetry requests.
- Recall pagination, retained and date-scoped search, capture context filters,
  bookmarks and notes, recorded-day navigation, and clearer evidence and coverage
  in summaries.
- Bounded, retryable recording retention cleanup and metadata-only diagnostics.

## Verification limits

Automated tests and browser viewport checks do not establish physical device
behavior. Real iOS/Android keyboards and gestures, Windows secure desktop, mixed
DPI monitors, and end-to-end remote media performance still need device testing.
Recall timestamps and observed coverage do not imply continuous recording or
claim-to-frame citations. See `ROADMAP_VERIFICATION.md` for the verification record.
