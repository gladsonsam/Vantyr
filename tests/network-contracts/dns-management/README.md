# Current DNS management wire fixtures

These synthetic, non-secret fixtures are generated by the server serializers
(`WorkerReadResponse` and `WorkerStatusBody`). They are the ONLY DNS management
wire fixtures: there is no versioned v1/v2 pair and no legacy reader. Both
validators parse these same files and recompute the digest from the one strict
canonical `ManagementConfig` shape, whose field order is `sources`, `catalog`,
`selected_services`, `runtime`.

`runtime` is a required field. A body without it, or any envelope carrying a
`schema_version` discriminator, is rejected by strict parsing rather than
upgraded. The digest of the current fixture config is
`4652ce3244e14658db02de0c05520507d0d92619a434a6a455a8309f5dbb6d37`.

Fixed timestamps keep content age reproducible: `applied_at` and the clear
attempt are original observations, not report freshness. These fixtures check
the wire contract; authenticated server/worker, download, durable-publication
and origin-hit tests provide the behavioral evidence.
